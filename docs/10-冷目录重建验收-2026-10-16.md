## 审核找出并修正的问题

- 安装入口硬编码 Codex PowerShell；改为 PATH/参数/环境变量。默认规划，实际部署须 `--install`。
- 原安装器即使记录 HRESULT 失败或 guard.stop，外层仍可能退出 0；现在判断阶段/结果并传播失败退出码。
- 运行库准备依赖人工从旧 Temp 找 CPU/TBB；新增固定归档 bootstrap 和统一构建入口。
- 新运行库布局曾把 CPU 插件也复制到工具旁，触发自动注册与显式注册冲突；已修正并完整重跑通过。
- 只解第一层部署 CAB 会缺插件；现在明确展开内层 Deployment.cab。
- 清理客户端脚本里未使用、且指向未收录调试文件的变量。
- 重启判据原先比较字符串，可能受 JSON 日期转换影响；现统一 UTC 时间，只接受更晚的实际启动。此修改尚未经过新的整机 GUI 验收。

早期一次模型准备超时缺少阶段输出，未确诊原因；测试工具现会保存超时输出。审计 C# 命令曾因测试工具的相对正斜线路径出错，改用绝对 Windows 路径后通过。这些错误不代表原版功能回归。
