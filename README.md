# 在无 NPU 电脑上研究 Windows AI 与原生功能

这里保存可接续的研究记录、已验证源码、原版载荷获取方法和恢复步骤。核对日期：**2026-10-16**。实机为 Xiaomi Book Pro 16 2022 / Intel i7-1260P / 无 NPU / Windows 11 x64 26300.9550。

## 当前结果

| 功能 | 状态 |
|---|---|
| AI 工作负载产品登记 | 已通过微软原版离线部署链完成，不再卡在“只有 MSIX、没有产品关系” |
| OCR | LNL 路线实测成功 |
| 语义相关模型/API | 另一轮 Gallery 测试报告成功；不是全系统搜索验收 |
| Click to Do | 原版识别、选择成功；用户重启后反馈复制和打开可用 |
| 原生 Win＋Q | 已验证并加入无终端启动器；需先启动约 15 分钟的会话 |
| Win＋单击 | 仍有界面闪现后消失的问题 |
| Studio 自动取景、背景模糊 | 原生面板、真实 CPU 推理和用户视觉验证通过 |
| Studio 固化 | 两个自启服务及故障恢复已做；整机重启后的效果仍待完整验收 |
| Recall、统一 Ready、其余全部 AI 功能 | 未实现，不能据上述成果推定可用 |
